Section 3(e): Zero-Flag Architecture

Unlike classical CISC or older architectures that rely on condition code registers (NZCV flags), LIMO completely eliminates flags to prevent:

  • Pipeline hazard interlocks between ALU & Branch stages
  • Secondary write ports on status registers
  • Out-of-order instruction scheduling bottlenecks
Conditionals compare registers directly in the execution stage via hlk (ha e lekana - beq) and hft (ha e feta - bgt).

LIMO 5-Stage Core Processor Architecture & Block Diagram

CS3520 Milestone M2 Technical Deliverable · Derived from RISC-V RV32I

1. Harvard Datapath

Separate Instruction Memory (IMEM) and Data Memory (DMEM) prevents structural memory access hazards during simultaneous instruction fetch and load/store access.

2. Section 3(e) Direct Branches

No NZCV status registers. Conditionals compare operands directly in EX (hlk / hft), preventing flag-dependency hazard interlocks.

3. Hazard Resolution

Full forwarding from EX/MEM and MEM/WB stages eliminates RAW stalls. Load-use dependency injects a 1-cycle bubble into ID/EX while freezing PC and IF/ID.
